# **Análise de Preço de Veículos**

### **Descrição do projeto**

Com o intuido de desnvolver um aplicativo web através de Streamlit, Pandas e Ploty Express para visualizar as informações sobre os veículos anunciados. Apresentamos uma análise exploratória de dados de anuncios de veículos usados.

### **Funcionalidades**

Temos dois gráficos interativos:

1. Histograma de Preço: apresenta a distribuição dos preços dois veículos anunciados;
2. Gráfico de Dispersão: apresenta a relação da quilometragem (odometro do veículo) e o preço do veículo para a venda.

Os gráficos foram feitos de forma utilizando o Plotly Express e são exibidos no aplicativo desenvolvido com Streamlit.

### **Tecnologias Utilizadas**

* Python;
* Pandas;
* Streamlit;
* Plotly Express;
* Jupyther Notebook.
